# Проверка канджи через Google — запуск на домашнем компьютере

Этот инструмент **не для сервера** — он запускается на твоём личном компьютере,
использует твой обычный IP и видимое окно браузера. Причина: сервер сразу
получил капчу на первом же запросе к Google (IP сервера уже помечен как
дата-центровый), а твой домашний компьютер — обычный пользователь.

Скрипт **не** пытается обходить капчу или подделывать браузер — если капча
всё же появится, он остановится и подождёт, пока ты её решишь вручную в
открытом окне.

## Установка (один раз)

Нужен Python 3.10+ (проверить: `python3 --version` в терминале / `python --version` в cmd на Windows).

```bash
cd heisig-google-check
python3 -m venv venv

# Linux/Mac:
venv/bin/pip install playwright
venv/bin/playwright install chromium

# Windows (cmd/PowerShell):
venv\Scripts\pip install playwright
venv\Scripts\playwright install chromium
```

## Запуск

```bash
# Linux/Mac:
venv/bin/python3 check_kanji.py

# Windows:
venv\Scripts\python check_kanji.py
```

По умолчанию проверяет 10 случайных ещё непроверенных канджи за один запуск —
открывается видимое окно браузера, скрипт сам ищет каждый канджи в Google и
ждёт 20–60 секунд между запросами (чтобы не выглядеть как спам). Займёт
где-то 5–10 минут на 10 штук.

Другие варианты запуска:
```bash
venv/bin/python3 check_kanji.py --count 20       # 20 штук за раз вместо 10
venv/bin/python3 check_kanji.py --id rtk523      # проверить конкретный канджи (境)
venv/bin/python3 check_kanji.py --resume-only    # не выбирать новые случайные, а
                                                  # добрать по порядку то, что осталось
```

Можно запускать раз в день (или когда вспомнишь) — скрипт помнит, что уже
проверено (`progress.json`), и не повторяется.

## Что получится

- `results.jsonl` — по одной строке JSON на каждый проверенный канджи: что
  нашёл в Google (`extracted_text`), что сейчас записано у нас в базе
  (`current_parts`), путь к скриншоту.
- `screenshots/` — скриншот страницы результатов для каждого канджи, на
  случай если автоматическое извлечение текста промахнулось (Google
  периодически меняет разметку страницы) — тогда можно просто открыть
  скриншот и прочитать глазами.

## Как переслать результаты обратно

Самое простое — скопировать содержимое `results.jsonl` и прислать мне в
чате. Если на этом компьютере тоже настроен git с доступом к репозиторию —
можно закоммитить `results.jsonl` и запушить, я прочитаю оттуда напрямую.

## Если через какое-то время всё снова стало возвращать пустые `extracted_text`

Значит Google поменял разметку страницы. Открой любой скриншот из
`screenshots/`, в обычном браузере зайди на тот же поисковый запрос, нажми
правой кнопкой на блок с ИИ-ответом → "Просмотреть код" (Inspect), найди его
CSS-класс/id и добавь его в список `AI_OVERVIEW_SELECTORS` в начале
`check_kanji.py`.
