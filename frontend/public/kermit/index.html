Software libraries and tools for glyphs

We develop open-source tools for working with CJK characters as shapes: breaking glyphs into named components, searching by those components, rendering them faithfully, and checking the data against what is actually drawn.

Use it from code

The search API is public. For example, characters containing both "sun" and "moon":

curl -X POST https://kanji.alteon.help/kanji/api/search/parts \
  -H 'Content-Type: application/json' \
  -d '{"parts": ["sun", "moon"], "depth": 1}'

Or add the MCP server to Claude Code:
claude mcp add --transport http kanji https://kanjimcp.alteon.help/mcp

How we work

  • Render it, don't reason about it. Every component is checked against the drawn glyph, not just against Unicode tables.
  • Provenance first. Each piece of data records where it came from; open sources are credited and nothing is attributed to a source it did not come from.
  • Tested. An isolated API test suite and more than 1,300 pinned decomposition checks run in CI on every push.
